# Hollywood Animal Pollux Editor

A Pollux Awards save editor for *Hollywood Animal*.  
《好莱坞动物》（Hollywood Animal）Pollux 奖项存档修改器。

> This tool was generated with OpenAI Codex.  
> 本工具由 OpenAI Codex 生成。

## English

### Features

- Replace a confirmed Pollux winner with another nominee from the same year and award category.
- Replace player-submitted films or talent after submission and before final nominees are generated.
- Replace final nominees before publication while preserving the score of each nominee slot.
- Simplified Chinese and English UI.

### Download

Download the latest single-file Windows build from [Releases](https://github.com/RyunFan/Hollywood-Animal-Pollux-Editor/releases/latest).

Current version: **v1.5.0**  
Platform: Windows 10/11 x64. No separate .NET installation is required.

### Usage

1. Launch the editor and click **Open Save…**.
2. Choose the year, award category, and nominee you want to edit.
3. Continue staging any other winner, submitted-entry, or final-nominee changes.
4. Click **Export All Changes…** and save the edited data under a new filename.
5. Back up the original game save, then place the exported file in the game's save directory when ready to use it.

Default save directory:

```text
%USERPROFILE%\AppData\LocalLow\Weappy\Hollywood Animal\Saves\Profiles\0
```

### Disclaimer

This is an unofficial fan-made tool and is not affiliated with Weappy or the game's publisher. Back up your saves before editing. Future game updates may change the save format and require an updated version of this tool.
